# Agent 与 Neo 原生联动

本说明对应当前源码，不代表公开的 0.9.0 安装包已经包含这些改动。

## 用户行为

- 回答中的 HTTP(S) 链接会展开右侧 Neo，在新标签打开并保留原页面。浏览器未启动时先启动；共享期间禁止新建标签的规则继续生效。失败不会自动改用系统浏览器。
- Codex、Claude、Pi、OpenCode 使用同一组 Neo 观察、导航、点击、填写、等待、截图和检查点工具。当前可见页面、原生 page ID 与任务上下文在每轮建立时绑定。
- `workbench_browser_edit` 的 `insert` 可在容器内或元素前后创建嵌套 HTML。返回的新引用可继续检查和修改，选中状态与预览记录同步到检查器。
- 创建、样式、文字和动效仍属于当前 DOM 预览；不会自动写入项目。原生动作使用 Neo 引用，检查器使用 Athena 引用，新建后通过新观察取得对应操作引用。
- 源码保存仍需用户明确要求，并由具有文件工具权限的 Agent 核对网页与项目关系后执行。

## 执行链路

| 执行器 | 工具接入 | 约束 |
| --- | --- | --- |
| Codex | app-server 动态工具 | 沿用已有任务权限与恢复流程 |
| Claude | 每轮私有 stdio MCP，转入认证的本机回环服务 | 只读 Read/Glob/Grep/Skill 与固定 Athena 工具清单；写入和命令工具关闭 |
| Pi | 显式 Athena 扩展注册宿主工具 | 宿主工具使用 Neo 权限链，本地文件/命令继续逐项审批 |
| OpenCode 1.x | ACP 的私有会话 MCP | 保留 CLI 原有拒绝规则，文件与命令逐次审批；宿主工具继续经过 Neo 权限链 |
| Gemini / Cursor | 未接入宿主 Neo | 保持当前限制，不伪装成具备网页执行能力 |

`src/main/agent-mcp.ts` 负责固定工具清单、认证、请求去重、结果转码和调用记录。CLI 不能替换宿主管理的 Neo 会话。临时凭据不进入提示词和项目配置；Claude 结束一轮即关闭连接、删除临时配置，Pi 的操作只在匹配的活动回合中接受。

Claude 保留新主线的只读 Read/Glob/Grep/Skill，并使用严格 MCP 配置接入 Neo。只读工具和精确 Athena 工具名合并在同一条 allowedTools 许可中；写入、命令、子任务和内联 shell 仍禁用。原生 init 必须报告 Athena 已连接且工具完整；`alwaysLoad` 与 `ENABLE_TOOL_SEARCH=false` 保证首轮可见。认证及 Provider 沿用 CLI 配置，原生联调使用独立 CLAUDE_CONFIG_DIR 和本地模型服务。

Pi 的扩展握手和浏览器工具握手均需成功。扩展自行生成 RPC 序号，避免不同回合复用模型调用编号时被误判为重复传输。

## 页面结构与撤销

结构使用声明式节点，每次最多 80 个节点、8 层和 60 KB 请求；只接受规定的 HTML 标签、属性和现有安全样式。禁止脚本、事件处理属性、危险 URL、敏感控件和重复 ID。新增按钮固定为普通按钮，新增输入控件不关联原网页表单。

预览记录保存创建节点的引用、原位置、节点身份与输入状态。撤销前检查文档、节点、后续编辑和当前输入；存在较新的网页内容或输入时拒绝删除。Shadow DOM 与 iframe 继续使用原有作用域，不能用相似选择器替代失效引用。

结构操作进入现有观察/执行/核对流程。失效或未知结果要求新观察及检查点；已成功的相同插入请求在当前回合内不重复执行。停止后关闭能力连接并结束运行中记录；迟到结果不会报作成功。共享、人工接管、上传和高级脚本的原有权限边界保留。
