# 语音界面的官方参考

调研于 2026-11-21。依据为 OpenAI 与 Anthropic 的官方帮助说明和官方页面内嵌截图。截图反映对应页面展示的版本，实际账号界面可能因平台、版本和功能发布进度不同。

## ChatGPT

2026-07-08 的 GPT-Live 发布页展示了天气、赛程和地图三张移动端界面图。图中主体和底部输入区延续白色表面，结果卡片位于当前聊天里，较小的蓝白语音标识出现在输入区上方。添加内容、文字输入和麦克风仍在底部，结束通话使用单独的黑色圆形按钮。配色观察来自这些官方实图。[GPT-Live 发布页及截图](https://openai.com/index/introducing-gpt-live/)

现行帮助说明确认，语音处于同一聊天中，用户可以边听边阅读回复、回看前文和输入文字。语音入口位于消息输入区域，通话时提供静音和退出控件。[ChatGPT Voice](https://help.openai.com/en/articles/20001274-chatgpt-voice)

2025-11-25 的官方更新将语音融入原聊天界面，支持在语音持续时阅读消息和查看图像、地图等结果。这说明“对话连续、内容仍可操作”是明确的产品行为。[ChatGPT 更新记录](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

桌面说明同样强调在现有任务中发起语音、沿用该任务的上下文和执行模型，并把后台工作的结果带回通话。该说明没有提供足以量测入场动画的录像。[ChatGPT 桌面语音](https://learn.chatgpt.com/docs/features/voice)

## Claude

现行官方帮助页的桌面截图，在原输入框右下方放置小型浅米色圆角声波按钮，旁边保留模型选择。启动后的控件截图显示，麦克风和浅蓝色的 Stop 按钮位于同一区域。官方步骤说明，用户说的话会填入聊天输入框，点击右下方 Stop 才退出语音。[Claude 语音说明及截图](https://support.claude.com/en/articles/11101966-use-voice-mode)

同页的移动端截图采用深色主题，语音入口与麦克风、附件控件放在同一个深色输入容器中。它支持的是“沿用界面主题”的观察，无法据此把所有移动端语音模式概括为白色。官方同时确认，文字和语音可在同一对话内切换并保留上下文。[Claude 语音说明及截图](https://support.claude.com/en/articles/11101966-use-voice-mode)

## Athena 的实现取舍

以下是根据上述交互做出的设计判断。

- 输入方式改变时，沿用当前输入区域的宽度、圆角、浅色表面和阅读位置，使进入语音成为同一控件的状态变化。
- 聊天历史与执行结果持续可见。语音相关动作使用原有尺寸、焦点和控件风格，真实麦克风状态与音量提供反馈。
- 浏览器协作时，将头像和必要控制收拢到网页上方，使用与工作台一致的表面颜色及轻阴影。展开和收起保持主体的相对位置。
- 进入、退出和展开由实际连续帧验证，系统减少动态效果时提供直接且清晰的状态切换。
